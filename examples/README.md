# Example briefs

The repository currently includes one public render, `case-01.png`. Do not commit a user's private source photo without permission.

## Case 01 — Canonical food launch

Use one named local food. Translate its texture, serving method, and natural packaging into a minimal foldable-device launch composition.

## Case 02 — Packaging variation

Keep the food recognizable while changing only the packaging logic to match a cup, sleeve, skewer, leaf, or no-package brief.

## Case 03 — Product suffix variation

Test `Fold`, `Duo`, `Plus`, `Pro`, `Pro Max`, or `Ultra` only when the suffix is supported by the food's product idea.
