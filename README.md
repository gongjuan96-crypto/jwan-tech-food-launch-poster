# jwan-tech-food-launch-poster

Jwan food-launch poster Skill: local snacks translated into product-launch and foldable-device visual language.

Version: 1.0.0

## Features

- Translate a named food's texture, serving method, signature feature, and packaging into a launch-object composition.
- Use product-specific suffix logic such as `Fold`, `Duo`, `Plus`, `Pro`, `Pro Max`, or `Ultra`.
- Keep the composition minimal, central, spacious, and recognizable as the food product.

## Usage

Use `$jwan-tech-food-launch-poster` with a food name and any required product copy, ratio, or brand direction.
